# 3DG + CloudCompare 功能整合：UI 方案 v5

本方案的第一阶段已进入桌面程序：单行菜单、三个工作区、紧凑半透明卡片、独立处理对象、地图快照，以及部分原版 CloudCompare 工具入口已经接通。其余章节仍是后续实施方案；交互预览中的点云、点数和运算结果均为示例。

当前已接入的原版工具包括复制、抽稀、分割、法向量、栅格化、ICP / 对应点配准、点云到点云 / 网格距离和选中对象导出；可用性受对象类型、选择数量及当前构建控制。扩展插件、批量处理、处理记录、结果统计等尚未完成。

## 1. 总体布局

**保持现有 3DG 风格：三维显示铺满整个内容区，所有工具和数据面板都采用上层半透明悬浮卡片。** 画布延伸到卡片背后，打开、收起卡片不改变画布尺寸和相机视角。顶部菜单与最底状态栏保留；菜单以下的内容区由三维视图完整占据。

保留左侧窄图层栏、右侧任务状态和底部航点条。将 **3DG Mission ▾** 放在菜单栏最左侧，与“文件、编辑、处理、分析、任务机、视图、设置”处于同一行，取消单独的品牌标题栏和工作区切换栏。点击 **3DG Mission ▾** 打开下拉菜单，包含 **任务监控 / 点云处理 / 对比分析** 三个工作区，当前工作区显示勾选标记。“全部工具”和连接状态放在这一行右侧。选择后收起菜单，点击菜单外部或按 Esc 也可关闭。切换工作区只替换悬浮工具和卡片内容，不清空数据，也不停止任务机通信。

卡片使用浅蓝白色半透明背景，默认约 84% 不透明度、细描边、轻阴影；内容与按钮保持清晰。左侧对象卡、右侧参数卡、顶部工具条均可独立收起；窄图标栏提供一键收起全部卡片，再次点击恢复。卡片以外区域直接响应三维操作，卡片内部操作不穿透到场景。卡片可拖动，位置与展开状态按工作区保存，拖动时限制在内容区内。

菜单调整为：**3DG Mission ▾、文件、编辑、处理、分析、任务机、视图、设置**，帮助入口可归入设置。插件按用途出现在“处理 / 分析”中，设置中的“扩展工具”负责显示各项功能的可用状态。

### 紧凑卡片规则

- 顶部工具条按内容宽度显示，约 440×40 px，不横跨全屏；合并快照、当前工具、双视图和导出入口。
- 左侧对象卡约 184 px 宽，默认只显示对象行。“选中对象属性”和“实时场景”折叠；没有处理结果时不显示空结果区。
- 右侧工具卡约 228 px 宽，标签与输入框同排；只常驻输入对象、关键参数和预览 / 应用按钮。迭代次数、精度等高级参数及操作说明合并为可展开区域。
- 去除重复的场景标题卡。图例压缩为右下角短条；距离分析需要时才展开色标。处理记录默认是左下角的小按钮，点击后展开记录。
- 收起卡片后保留窄图标栏，点击恢复。工具、对象和参数入口仍可访问，不通过缩小正文文字来换取面积。
- 三维画布继续铺满内容区，所有卡片继续半透明浮在上层。

| 区域 | 任务监控 | 点云处理 | 对比分析 |
| --- | --- | --- | --- |
| 顶部 | 现有任务工具、连接状态 | 导入、快照、编辑、配准、网格、导出 | 选参考与待测对象、距离、截面、体积、导出 |
| 左侧悬浮 | 现有窄图层栏；按需展开半透明数据卡 | 紧凑对象卡，默认约 184 px，属性折叠 | 对象树卡片，显示参考 / 待测角色 |
| 铺满底层 | 实时点云、地图、无人机、航线 | 被选对象和操作预览，延伸到卡片背后 | 叠加或同步双视图，仍铺满底层 |
| 右侧悬浮 | HUD、任务机状态、任务操作三张卡片 | 当前工具的对象、参数、预览、应用卡片 | 比较设置、结果统计卡片 |
| 底部悬浮 | 航点条；日志按需打开 | 处理记录窄条，可展开 | 结果摘要、色标和导出入口 |

监控默认保持原有面板；进入处理 / 分析后，任务状态缩为顶部状态条，告警继续可见，可一键回到任务监控。视频默认折叠，可重新显示。

桌面以 1360×860 为基准。1024×710 时左侧对象卡可收起，右侧约 228 px，高级参数折叠；卡片需避开底部操作条。窄屏预览中卡片可上下排列在三维背景之上，底层画布仍连续铺满，不被划分为中间一栏。实际桌面窗口保留最小尺寸。

## 2. 数据对象树

按来源分组，而不是把所有文件合并成一张地图：

```text
实时场景
  实时点云                         持续更新
  累积地图                         可创建快照
  无人机 / 航线 / EGO / 实飞轨迹    场景图层
项目数据
  地图快照_001                     点云
  参考扫描.ply                     点云 / 网格
  现场扫描.pcd                     点云
处理结果
  现场扫描_去噪                    点云
  现场扫描_配准                    点云 + 变换记录
  距离分析_001                     点云 + 距离标量场
  地表重建_001                     网格
```

每行提供可见性、对象类型、名称；选中后右侧显示点数 / 面数、坐标系、单位、源文件、属性和处理来源。支持多选、重命名、分组、复制、删除、导出、适配视图；点击“可见”不改变选择。

实时场景对象不能直接作为会修改数据的算法输入。提供“创建快照”：在明确时刻生成独立处理对象，同时保存地图 ID、坐标系和单位。已有离线文件支持同时导入多个，保留原始网格、颜色、法向量、标量场、材质和全局坐标偏移。

实时地图和离线对象的坐标系或单位不一致时，在对象详情中解释差异，并提供单位 / 坐标变换设置；不得静默叠加为已经对齐的数据。

## 3. 全部功能的界面归属

| 类别 / 入口 | 功能范围 | 主要交互 |
| --- | --- | --- |
| 文件 | 导入 / 导出、项目保存 / 打开、选中对象导出、格式转换 | 显示当前构建实际支持的格式，以及目标格式会丢失的属性 |
| 视图与属性 | 颜色、法向量、标量场、色带、点大小、可见性、透明度、相机、多视图 | 在对象属性和视图工具中调整；显示原始点数和预览点数 |
| 编辑 | 平移 / 旋转 / 缩放、矩阵变换、合并、分割、裁剪、抽稀、去噪、重复点处理 | 选择对象后打开工具面板；交互裁剪有明确的完成 / 取消入口 |
| 配准 | 对应点粗配准、ICP 精配准、中心 / 尺度匹配、变换矩阵导出 | 显式指定参考对象和待配准对象；可交换角色、查看对齐前后 |
| 几何与属性计算 | 法向量与方向、密度、曲率、粗糙度等几何特征、标量场运算和阈值过滤、统计 / 直方图 | 新结果字段加入所选对象的派生副本，在颜色通道中选择 |
| 截面与地形 | 截面提取、剖面展开、栅格化、等高线、2.5D 体积 | 画布显示截面工具或范围，右侧设置方向、步长、网格尺寸等 |
| 距离与误差 | 点云到点云、点云到网格、点云到基本几何体、M3C2 | 参考 / 待测角色明确；显示算法、距离单位、色标、有效点统计 |
| 网格 | 三角化、网格采样、平滑、面积 / 体积、泊松重建、布尔运算 | 点云 / 网格类型限制可见，重建前提示缺少法向量等输入条件 |
| 检测与分类 | 基本几何拟合、RANSAC、CSF 地面分离、连通分量、手工分类、CANUPO / 3DMASC 等扩展 | 类别作为标量字段或独立结果对象显示，保留原始数据 |
| 显示增强 | EDL、SSAO、环境光遮蔽 | 放在“视图 → 显示增强”，与几何处理分开 |
| 其他扩展 | qPCL、地质结构、树木分离、动画等已适配插件 | “更多工具”按用途列出；必要时先使用插件原有对话框 |
| 批量处理 | 对多个文件重复已支持的处理流程 | 文件清单、参数模板、运行进度、成功 / 失败记录 |

“全部整合”包含功能入口、输入对象适配、结果保存和可用性反馈。依赖平台、外部 SDK 或模型文件的扩展，不会因出现按钮就被标为可用。设置中的工具列表区分：**可用 / 未编译 / 缺少运行依赖 / 当前平台不支持**。

PCD 沿用并扩展 3DG 现有读取能力；其他格式通过 CloudCompare 的实际加载器注册。LAS/LAZ、E57、STEP、FBX 等按对应依赖逐项接入，导出界面明确格式对字段的保留能力。

## 4. 统一工具面板

各工具遵循相同顺序：

1. **选择输入**：单对象或参考 / 待测对象，显示名称、类型、点数、坐标单位。
2. **设置参数**：先显示必要参数，高级项默认折叠；参数单位写在标签旁。
3. **预览**：若工具支持，则对标明数量的样本计算预览；不支持预览的工具直接显示“运行”。
4. **应用**：生成新对象，或在保留原对象的前提下生成变换 / 属性副本。
5. **使用结果**：查看前后差异、保存、导出；点云结果可选择“用于任务地图”。

执行中显示步骤、进度及可用的取消动作；不支持中途取消的算法明确显示“运行中，无法中止”，不能放置无效取消按钮。计算失败保留输入对象并显示具体原因。操作记录保存输入对象、参数、算法、结果和时间；删除派生结果不影响原数据。撤销能力按操作支持情况显示，不能承诺所有插件都可撤销。

不同拾取工具互斥：航点拾取、裁剪、多点测量和对应点配准不会同时响应鼠标。画布顶部显示当前交互模式和退出按钮，Esc 退出当前交互。

## 5. 对比分析的典型流程

导入“参考扫描”和“现场扫描” → 必要时先粗配准 / ICP → 指定参考与待测角色 → 选择点云距离或 M3C2 → 设置参数 → 运行 → 显示距离着色对象、统计分布和超过阈值的比例 → 导出结果点云与统计表。

ICP 面板展示重叠率、迭代限制、使用的点数、变换矩阵及配准 RMS。距离结果展示单位、有效点数、均值、RMS、分位数等适用统计量。无符号最近邻距离不标为“正负形变”，有符号结果和 M3C2 的置信信息按算法单独说明。

“叠加 / 双视图”仅影响显示；两侧视图可同步相机。调整颜色范围不重新计算距离，修改算法参数会使旧预览明确标为过期。

## 6. 与任务监控的衔接

“用于任务地图”只对符合条件的点云结果开放。操作前显示结果名称、地图 ID、坐标系、单位及当前任务地图，校验后明确替换本地参考地图。是否暂停实时累积需在操作面板说明，避免后续帧覆盖处理结果。任务机上传与本地显示是两个独立动作。

监控与离线处理共享视图和数据入口，但实时点云、航线、无人机等临时图元的生命周期独立。处理时持续收到的新点不改变已经提交给算法的快照。

## 7. 现有代码对方案的约束

- `MissionController::buildUi()` 会禁用原 QAction、隐藏原菜单、Dock 和工具栏。因此不能仅重新显示菜单；需要按工作区重新管理动作和对象选择。
- `MissionController` 的实时图层挂在 GL 窗口 ownDB 下，不能直接塞进默认对象树供原算法操作。处理数据应进入可管理的持久对象容器，并通过适配层调用原算法 / 插件。
- `loadMapPath()` 当前将文件展开成 XYZRGB 点集，并替换 `mapPoints_`。多对象、网格、法向量和标量场需要新导入通路，不能继续沿用这条简化路径。
- 现有 PCD 功能已存在；多格式能力要同时验证插件被加载以及实际文件可读写。

## 8. 实施顺序与验收

1. 工作区、对象树、对象选择、导入 / 导出和任务地图快照。
2. 编辑、裁剪、抽稀、属性计算、配准、基础距离、截面、体积和网格工具。
3. 插件能力与依赖接入、多格式覆盖、结果记录、批量任务及显示增强。

最终验收覆盖：实时接收期间创建快照并完成处理；多个对象不丢失属性；配准角色可交换；结果生成、导出及重新打开；处理时导航 / 状态刷新正常；航点与处理工具的鼠标模式互斥；1024×710 布局可用；各插件至少通过一个实际功能操作。编译通过不能代替这些交互验收。
